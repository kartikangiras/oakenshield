How it works

One check between a pull request and your results

Flagsmith matches event names and variation keys exactly. A tidy up that passes tests and review can still stop an experiment from counting. Oakenshield reads what Flagsmith expects and compares it with what the code now does.

  1. 1

    Reads Flagsmith

    For every running experiment: the flag, its variations, the metric events and the segments that decide the audience. Through the Admin API, or the Flagsmith CLI logged in with GitHub OIDC.

  2. 2

    Reads the diff

    Finds exposure calls, branches on variation keys, trackEvent calls, SDK versions, enableEvents and identity code in what the pull request changes.

  3. 3

    Blocks only what it can prove

    One comment in plain words, a suggested fix you accept with one click, and an override label for maintainers that gets recorded.

Where it runs

Wherever code changes, not in another tab

  • Pull requests

    A red check you can trust. The GitHub Action comments once per pull request, posts the fix as a suggestion and fails the check on a blocking finding.

  • Coding agents

    Agents check their own edits. Claude Code, Cursor and other MCP clients call check_experiment_impact before they finish, and stop before breaking a test.

  • Terminal and other CI

    Catch it before you push. experiment-guard check reads uncommitted work or any two refs and exits with code 1 on a block.

  • Flagsmith webhooks

    Watches the other side too. When someone starts, pauses or retargets an experiment, every open pull request is checked again against the new setup.

FAQ

Questions before you add it

What does it need from Flagsmith?

Read access to the environment where your experiments run: an organisation API key, or the Flagsmith CLI logged in with GitHub OIDC so no key is stored in your repository.

Does it change anything in Flagsmith or my code?

No. It only reads. Every fix is a suggestion that a person accepts, and every override is a label a maintainer adds.

Will it block harmless pull requests?

Only rules that can prove the code disagrees with Flagsmith block by default. Everything else is a warning or a note, and you can change any rule's level in one config file.

What if Flagsmith is unreachable?

The check fails open. It says so in the comment and lets the pull request through.

Which languages does it read?

JavaScript, TypeScript and Python call sites. The SDK version rule also covers Go, Java and Flutter projects.

Is the dashboard data real?

The overview, checks and alerts come from FirstPR, a sample app with 22 seeded pull requests. The A/B test that picks your first screen is real and runs on Flagsmith.

What does the demo record about me?

A random ID kept in your browser, the version you saw, and two events: running a check and copying a set up snippet. They go to Flagsmith for our A/B test. Oakenshield collects nothing else.

Is it free?

Yes. Oakenshield is open source under the MIT license, and the demo needs no account.
